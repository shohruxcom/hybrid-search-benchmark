# hybrid-search-benchmark

Benchmarking suite for hybrid (lexical + dense) retrieval systems.

## Overview

Tools and datasets to evaluate combinations of BM25/sparse and dense vector retrieval, with focus on reproducibility and clear metrics.

## Goals

- Fair comparison of hybrid ranking strategies
- Support for common IR metrics (nDCG, MRR, Recall)
- Easy extension to new models and datasets
